プライバシーポリシー
Privacy Policy

制定日・最終更新日 / Effective: 2026-11-18

Kanberi KPI Tracker（以下「本ツール」）は、運営者「かんなべりーきゅーと」（以下「運営者」）が、自身の SNS 投稿の成果を記録・分析するために使用する個人用ツールです。本ポリシーは、本ツールが取り扱う情報とその扱い方を説明します。
Kanberi KPI Tracker ("the Tool") is a personal tool used by its operator, Kanberi, to record and analyze the performance of the operator's own social media posts. This policy explains what information the Tool handles and how.

1. 取得する情報 / Information we collect

TikTok（Login Kit / Display API）open_id、表示名・アバター等の基本プロフィール（user.info.basic）、自分が投稿した動画の ID・タイトル/説明文・投稿日時・視聴回数・いいね数・コメント数・シェア数（video.list）
open_id and basic profile; IDs, titles/descriptions, post time, and view/like/comment/share counts of the authorizing user's own videos.
認証情報 / TokensTikTok が発行するアクセストークン・リフレッシュトークン（データ取得のためだけに使用）
Access and refresh tokens issued by TikTok, used only to fetch the data above.
YouTube（YouTube Data API）運営者自身の動画の公開統計（視聴回数・高評価数・コメント数・タイトル・公開日時）
Public statistics of the operator's own YouTube videos.
お問い合わせ / Contactお問い合わせフォームに入力されたメールアドレスと本文
Email address and message submitted through the contact form.

本ツールは、運営者本人以外の TikTok ユーザーのデータを取得しません。
The Tool does not collect data about any TikTok user other than the operator.

2. 利用目的 / How we use it

  • 投稿ごとの伸び（視聴回数の推移、目標達成率、エンゲージメント率など）を記録・集計し、ダッシュボードに表示するため
    To record and summarize post performance and display it on a private dashboard.
  • お問い合わせへの回答のため
    To respond to inquiries.

広告配信、プロファイリング、第三者への販売には一切使用しません。
We never use the data for advertising, profiling, or sale.

3. 保存場所と管理 / Storage and security

取得したデータは、運営者本人の Google アカウント内の Google スプレッドシートおよび Google Apps Script（スクリプトプロパティ）に保存されます。共有設定は運営者のみに限定し、トークンは公開されない領域で管理します。
Data is stored in a Google Sheet and Google Apps Script properties within the operator's own Google account, accessible only to the operator. Tokens are kept in non-public script properties.

4. 第三者提供 / Sharing

法令に基づく場合を除き、取得したデータを第三者に提供・販売・貸与しません。データの処理には Google（Google Workspace / Apps Script）および TikTok・YouTube の API を利用します。
We do not share, sell or rent data to third parties except as required by law. Processing relies on Google services and the TikTok and YouTube APIs.

5. 保存期間 / Retention

記録データは分析に必要な期間保存し、連携を解除した場合やご依頼があった場合は速やかに削除します。トークンは連携解除時に削除します。
Records are kept as long as needed for analysis and deleted promptly upon disconnection or request. Tokens are deleted when the connection is revoked.

6. 連携の解除・データの削除 / Revoking access and deletion

TikTok アプリの「設定とプライバシー」→「セキュリティ」→「アプリの権限」から、いつでも本ツールとの連携を解除できます。保存データの開示・訂正・削除のご依頼は、下記のお問い合わせフォームからご連絡ください。
You can revoke access at any time in the TikTok app (Settings and privacy → Security → Manage app permissions). To request access to, correction of, or deletion of stored data, please use the contact form below.

7. 改定 / Changes

本ポリシーを改定する場合は、このページで改定日とともにお知らせします。
Any changes will be posted on this page with the updated date.
